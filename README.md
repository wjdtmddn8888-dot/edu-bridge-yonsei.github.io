# EDU:BRIDGE — 팀 육하원칙

연세대학교 시민사회와 자원봉사 프로젝트 웹사이트. https://edubridgenet.com

핵심 메시지: 교육 격차는 성적만의 문제가 아니다. EDU:BRIDGE는 아동·청소년을 찾아가 함께 만들고 이야기 나누는 시간을 연다. 소득별 통계는 소개 페이지의 배경으로만 다루고, 가정 형편을 단정하는 표현은 피한다.

## 페이지 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 홈 (학교 사진과 활동 일정, 함께하는 곳, 핵심 수치, 페이지 안내) |
| `about.html` | 소개 (육하원칙 5W1H, 만들기 활동을 고른 이유) |
| `background.html` | 배경 (소득 구간별 사교육비 차이, 방과 후 희망과 실제의 차이, 출처) |
| `partners.html` | 함께하는 곳 (기관을 찾아온 과정, 협력 기관, 만나는 아동·청소년) |
| `activity.html` | 활동 (두 활동의 날짜·진행 순서) |
| `how.html` | 진행 방식 (소그룹 진행, 멘토 역할, 멘토의 약속) |
| `archive.html` | 아카이브 (날짜순 타임라인, 완료/예정 필터. 사진은 `img`를 넣은 기록에만 표시) |
| `team.html` | 팀 (팀원과 학과) |

예전 주소(`map.html`, `problem.html`, `program.html`, `kit.html`)는 새 페이지로 자동 이동합니다.

## 공용 파일
- `assets/style.css` — 모든 페이지 공용 스타일
- `assets/main.js` — 공용 스크립트 + 데이터 (맨 위에 모여 있음)
- `assets/pretendard.woff2` — 폰트

## 수정 방법
- **활동 날짜·내용**: 세 군데에 적혀 있으니 함께 고칩니다.
  - `index.html` — 첫 화면의 일정 카드, 페이지 안내 카드(02 · 활동)
  - `activity.html` — 활동 카드(날짜, 인원, 진행 순서)
  - `assets/main.js`의 `ARCH` 배열 — 아카이브 카드
- **활동이 끝난 뒤**: `ARCH`에서 해당 항목의 `st`를 `"ok"`로 바꾸고 `d`에 소감을 적습니다. 사진은 `img/`에 넣고 `img: "img/파일명.jpg"`를 추가하세요. `activity.html`의 배지("진행 예정", "예정")도 바꿔주세요.
- **팀원**: `assets/main.js`의 `TEAM` 배열.
- **메뉴·푸터**: 각 HTML 파일에 같은 메뉴가 들어 있으니 5개 파일을 함께 고쳐야 합니다.
- **통계 수치**: `background.html`, `about.html`(5W1H의 WHY), `index.html`에 있습니다. 바꿀 때는 출처와 기준 연도를 함께 고쳐주세요.

## 만나는 대상
서울특별시립 아동푸른센터(은평구)에서 보호받으며 생활하는 아동·청소년. 센터는 보호가 필요한 아동의 상담·치료·보호·교육과 가정 복귀를 돕고 학대 피해 아동을 보호하는 서울시립 아동복지시설이다. 사이트에서는 센터의 역할만 설명하고, 참여 아동 개인의 사정은 적지 않는다.
