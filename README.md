# EDU:BRIDGE — 팀 육하원칙

연세대학교 시민사회와 자원봉사 프로젝트 웹사이트. https://edubridgenet.com

핵심 메시지: 교육 격차는 성적만의 문제가 아니다. EDU:BRIDGE는 아동·청소년을 찾아가 함께 만들고 이야기 나누는 시간을 연다. 소득별 통계는 소개 페이지의 배경으로만 다루고, 가정 형편을 단정하는 표현은 피한다.

## 페이지 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 홈 (학교 사진과 활동 일정, 함께하는 곳, 페이지 안내) |
| `about.html` | 소개 (육하원칙 5W1H, 방향을 정하기까지, 만들기를 고른 이유, 나눔 요약, 자세한 예산 자료는 배경) |
| `background.html` | 배경 (소득 구간별 사교육비 차이, 방과 후 희망과 실제의 차이, 아이들의 방과 후 핵심 수치, 지역아동센터 운영비, 출처) |
| `partners.html` | 함께하는 곳 (기관을 찾아온 과정, 협력 기관, 만나는 아동·청소년) |
| `activity.html` | 활동 (두 활동의 날짜·진행 순서) |
| `archive.html` | 아카이브 (준비 과정·활동으로 나눈 카드. 누르면 자세히 보기 창, 사진은 같은 화면에서 크게 보기) |
| `result.html` | 결과 (돌아보며, 시행착오, 예산, 소감) |
| `team.html` | 팀 (팀원과 학과) |

예전 주소(`map.html`, `problem.html`, `program.html`, `kit.html`, `how.html`)는 새 페이지로 자동 이동합니다. `how.html`(진행 방식)의 멘토 역할·약속은 `activity.html#mentors`로 옮겼습니다.

## 공용 파일
- 각 HTML에서 `style.css?v=…`, `main.js?v=…`처럼 버전 숫자를 붙여 둡니다. CSS나 JS를 고치면 이 숫자를 8개 파일 모두 새 값으로 바꿔야 방문자 브라우저에 남은 예전 파일 대신 새 파일을 받습니다. (GitHub Pages는 파일을 10분간 캐시합니다.)
- `assets/style.css` — 모든 페이지 공용 스타일
- `assets/main.js` — 공용 스크립트 + 데이터 (`ARCH`, `TEAM`, `BUDGET`이 맨 위에 모여 있음)
- `assets/pretendard.woff2` — 폰트

## 수정 방법
- **활동 날짜·내용**: 세 군데에 적혀 있으니 함께 고칩니다.
  - `index.html` — 첫 화면의 일정 카드, 페이지 안내 카드(02 · 활동)
  - `activity.html` — 활동 카드(날짜, 인원, 진행 순서). 만들기(`#make`)가 위, 나눔(`#share`)이 아래
  - `partners.html` — 기관을 찾아온 과정 타임라인, 기관 카드
  - `assets/main.js`의 `ARCH` 배열 — 아카이브 카드
- **활동 상태(완료 / 오늘 / 진행 예정 / 예정)는 날짜를 보고 저절로 바뀝니다.** 홈 일정 카드, 활동 카드 배지, 아카이브 카드, 함께하는 곳 타임라인의 "예정" 글자가 모두 한국 시간 기준 오늘 날짜를 따라갑니다. 날짜가 미뤄지면 `ARCH`의 `date`와 HTML의 `data-date`·`data-until` 값만 고치면 됩니다. 주소 끝에 `?today=2026-12-08`처럼 붙이면 그날 기준으로 미리 볼 수 있습니다. 쓰는 법은 `assets/main.js`의 "날짜에 따라 활동 상태 바꾸기" 설명에 있습니다.
- **활동이 끝난 뒤**: `ARCH`에서 해당 항목의 `d`를 소감으로 바꿔 적습니다. 자세히 보기 창에만 넣을 긴 글은 `more: ["문단1", "문단2"]`로 적습니다. 사진은 `img/`에 넣고 `imgs: ["img/파일명.jpg"]`를 추가하세요(첫 장이 카드 표지). 각 기록은 `archive.html#r-아이디`로 바로 열 수 있습니다.
- **팀원**: `assets/main.js`의 `TEAM` 배열.
- **예산**: `assets/main.js`의 `BUDGET` 배열. `cost`에 숫자만 적으면(예: `12000`) 소계와 합계가 자동으로 계산됩니다. 아직 모르는 금액은 `null`로 두면 "정리 중"으로 보입니다. 예상 금액에는 `est: true`를 붙이고, 확정되면 지웁니다(묶음 옆 "예상" → "확정").
- **결과 페이지(`result.html`)**: 활동이 끝나면 돌아보며 카드의 "활동 후 작성" 배지를 지우고 내용을 적습니다. 시행착오는 `li` 한 줄씩 더합니다. 소감도 활동 후 "활동 후 작성" 배지 자리에 적습니다.
- **메뉴·푸터**: 각 HTML 파일에 같은 메뉴가 들어 있으니 8개 파일을 함께 고쳐야 합니다.
- **통계 수치**: `background.html`, `about.html`(5W1H의 WHY), `index.html`에 있습니다. 바꿀 때는 출처와 기준 연도를 함께 고쳐주세요.

## 만나는 대상
서울특별시립 아동푸른센터(은평구)에서 보호받으며 생활하는 아동·청소년. 센터는 보호가 필요한 아동의 상담·치료·보호·교육과 가정 복귀를 돕고 학대 피해 아동을 보호하는 서울시립 아동복지시설이다. 사이트에서는 센터의 역할만 설명하고, 참여 아동 개인의 사정은 적지 않는다.

## 공유 미리보기 (카카오톡 등)
- 각 HTML의 `<head>`에 `og:title`, `og:description`, `og:image` 태그가 있습니다. 페이지 제목·설명을 바꾸면 `og:` 태그도 함께 고칩니다.
- 대표 이미지는 `img/og.jpg`(1200×630)입니다. 바꿀 때도 같은 크기로 만듭니다.
- 카카오톡은 미리보기를 한동안 저장해 둡니다. 바꾼 뒤에도 예전 모습이 나오면 카카오 공유 디버거(developers.kakao.com → 도구 → 공유 디버거)에서 주소를 넣고 캐시를 초기화합니다.
